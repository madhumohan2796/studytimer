# Pomodoro Timer Design Guidelines

## Aesthetic Stance
**Minimalist Desktop App** — A focused productivity tool designed for desktop screens. Large, confident timer display, generous whitespace, and a calm environment that encourages concentration.

## Typography
- **Display (Timer)**: Large condensed numerals with tabular figures for clean alignment
- **UI Labels**: Clean sans-serif for mode selection and metadata
- **Hierarchy**: Timer is hero, everything else is supporting structure

## Color Palette
**Warm focus mode** — Textured cream/paper background creates a calm, desk-like environment.

- Background: warm cream (#F5F1E8)
- Foreground: deep charcoal (#2C2C2C)
- Primary: muted terracotta (#C85C3F) for the timer ring and active states
- Secondary: soft warm gray (#E8E4DC) for inactive elements
- Muted: warm gray (#8B8478) for labels

## Layout Principles
1. **Desktop-first** — Uses full viewport width, designed for 1440px+ screens
2. **Single focal point** — Massive circular timer dominates the center
3. **Horizontal organization** — Mode switcher and controls use horizontal space
4. **Breathing room** — Extremely generous spacing between elements
5. **Asymmetric balance** — Session count offset to create visual interest

## Craft Details
- Large circular progress ring (400-500px diameter)
- Smooth animation on progress
- Subtle paper texture on background
- Minimal borders; structure through spacing and color
- Large, tactile controls with generous hit areas
- Tabular numerals for timer digits
